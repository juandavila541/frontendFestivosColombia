# Festivos Colombia - Frontend

API (backend): https://github.com/juandavila541/apiFestivosColombia

## Ejecutar

1. Ejecutar la API con el perfil `https` (puerto 7085) y la base de datos `Festivos` creada.
2. Instalar dependencias (solo la primera vez):
   ```
   npm install
   ```
3. Iniciar el frontend:
   ```
   ng serve
   ```
4. Abrir http://localhost:4200

Si PowerShell bloquea `npm` o `ng`, usar `npm.cmd install` y `npx.cmd ng serve`.
